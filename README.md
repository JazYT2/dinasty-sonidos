# DINASTY 2 — pack de sonidos

Resource pack de efectos de sonido para el servidor de Minecraft **DINASTY 2**
(1.21.1 / NeoForge).

El servidor lo reparte solo: al entrar se descarga y se aplica. **No hay que
instalar nada a mano.**

## Qué trae

138 efectos, reproducibles en el juego con `/sonido <nombre>`.
El tabulador autocompleta los nombres. `/sonido` a secas abre la lista.
